# Редактор публикаций и объявлений: сравнение вариантов

> **Статус: решение принято.** Владелец 12.11.2026 выбрал рекомендованный
> вариант — Tiptap 3 + JSON (Q-57). Ниже — исследование агента, на котором
> основан выбор. Версии и
> лицензии проверены через `npm view` 12.11.2026.

## Что требуется от редактора

Требования: PUB-10–PUB-12 (форматирование, ссылки, изображение по URL,
таблица, спецсимволы, линия, отмена/повтор, очистка), PUB-04 (предпросмотр),
PUB-09 и MKT-11 (поиск по тексту), PUB-15 и Q-56 (галерея, встраивание
YouTube/VK). Тот же редактор используется рынком (MKT-04) без загрузки файлов.

Ограничения проекта, которые отсекают часть вариантов:

| Ограничение                               | Следствие для редактора                                                                                  |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| Бесплатно, публичный репозиторий          | Лицензия MIT/BSD/MPL без ключа; платные расширения и облако не используются                              |
| Tailwind — единственная система стилей    | Редактор без собственных CSS-тем либо с отключаемыми стилями; оформление — классами Tailwind             |
| Без inline-стилей, цвета только токенами  | Цвет и размер текста — не `style="color:…"`, а атрибут из короткого списка токенов, отображаемый классом |
| Безопасность (PUB-12, GEN-02)             | Сервер не доверяет присланному содержимому: проверка по белому списку и показ без `innerHTML`            |
| Одна Edge Function, лёгкий холодный старт | Серверная проверка без DOM и без тяжёлых зависимостей — желательно только zod                            |
| Мобильные устройства обязательны          | Надёжный ввод на Android/iOS (IME, автозамена, выделение)                                                |
| Storybook для каждого компонента `ui/`    | Чем больше копируемых UI-компонентов приносит редактор, тем больше историй нужно поддерживать            |
| React 19, TypeScript strict               | Актуальная поддержка React 19 и типы                                                                     |

### Кого исключаем сразу

- **CKEditor 5, TinyMCE** — GPL или коммерческая лицензия с ключом,
  собственные темы CSS. Противоречат условию «бесплатно» и правилу стилей.
- **Quill 2** — последний выпуск январь 2025, готовые CSS-темы, слабые
  таблицы.
- **BlockNote** — интерфейс блоков «как Notion» вместо панели форматирования
  из PUB-10, собственные стили, часть функций под GPL. Внутри всё равно
  Tiptap — проще взять его напрямую.

### Tiptap 3

- **Плюсы.** Самая популярная обёртка над ProseMirror, активно выпускается
  (3.33 — ноябрь 2026). Все нужные функции в открытых MIT-пакетах:
  StarterKit (форматирование, списки, цитата, линия, отмена/повтор, ссылки),
  `extension-table`, `TextStyleKit` (цвет, размер), `TextAlign`, `Image`,
  `Youtube`. Headless: панель инструментов собираем из своих shadcn-кнопок,
  базовый CSS отключается (`injectCSS: false`), нужные свойства задаются
  утилитами Tailwind на редактируемом блоке. `@tiptap/static-renderer`
  превращает JSON в React-элементы без редактора и без `innerHTML` — путь
  показа в ленте и предпросмотре. ProseMirror — лучший по надёжности
  мобильного ввода среди открытых движков.
- **Минусы.** Платные Pro-расширения и облако существуют рядом — их нужно
  явно запретить (правило в AGENTS.md). Цвет и размер из `TextStyleKit`
  пишутся inline-стилем, поэтому вместо них — своя небольшая метка с
  атрибутом-токеном (`tone: 'gold' | …`, `size: 'sm' | 'lg'`), которая
  отображается классом. VK-видео — свой узел (у YouTube есть готовый).
  Объём пакета заметный — редактор загружается лениво только на странице
  правки.

### Lexical

- **Плюсы.** MIT, развивается Meta, тема — прямое соответствие «тип узла →
  класс», что хорошо ложится на Tailwind. Высокая производительность.
- **Минусы.** До 1.0, ежемесячные выпуски с изменениями API. Больше кода
  своими руками (панель, ссылки, вставка изображения, плагины). Стили
  текста хранятся строкой CSS — та же переделка, что у Tiptap. Показ без
  редактора: готового React-рендерера из JSON нет — либо read-only
  редактор, либо свой рендерер. В 2026 всё ещё регулярные исправления ввода
  на Android.

### Plate

- **Плюсы.** Компоненты уже на shadcn/ui и Tailwind, есть `PlateStatic`
  для показа.
- **Минусы.** Slate: ввод на Android исторически слабое место. CLI Plate
  добавляет десятки компонентов в проект — по нашему правилу каждому в
  `src/components/ui/` нужна история Storybook и переоформление токенами.
  Частые мажорные версии (53-я), много пакетов. Сильная сторона —
  ИИ-функции и Plate Plus — нам не нужны.

## Формат хранения и безопасность (для любого headless-варианта)

Сравниваются два способа хранить содержимое.

| Критерий                    | JSON документа (рекомендуется)                                             | Очищенный HTML                                             |
| --------------------------- | -------------------------------------------------------------------------- | ---------------------------------------------------------- |
| Проверка на сервере         | zod-схема белого списка узлов, меток и атрибутов в `_shared/contracts/`    | HTML-санитайзер в Deno (новая зависимость, холодный старт) |
| Показ в браузере            | React-элементы из JSON, `innerHTML` не используется                        | `innerHTML` + DOMPurify вторым слоем                       |
| Новые зависимости           | Только редактор                                                            | Редактор + серверный санитайзер + DOMPurify                |
| XSS-набор тестов            | На zod-схеме и рендерере                                                   | На двух санитайзерах                                       |
| Поиск (PUB-09, MKT-11)      | Сервер извлекает текст из JSON в колонку `search_text` при сохранении      | Нужно отдельно вырезать теги                               |
| Цвет/размер только токенами | Атрибут — перечисление в схеме                                             | Разбор и фильтрация `style`                                |
| Ссылки, изображения, видео  | Схема пропускает `https`/`http`/`mailto`, видео — только YouTube/VK-адреса | То же правилами санитайзера                                |

## Рекомендация агента

**Tiptap 3 (только MIT-пакеты) + хранение JSON + серверная zod-схема +
показ через `@tiptap/static-renderer` в React.**

1. Причины: все функции PUB-10/11 есть в открытых пакетах; лучший мобильный
   ввод; headless — оформление полностью Tailwind и shadcn; показ без
   `innerHTML`; на сервере новых зависимостей нет, только zod; поиск по
   извлечённому тексту.
2. Правила, которые нужно записать вместе с решением:
   - Используются только пакеты `@tiptap/*` с лицензией MIT; Pro-расширения
     и Tiptap Cloud не подключаются.
   - Редактор загружается лениво (только экран правки).
   - Цвет и размер текста — свои метки с атрибутом-токеном, не `TextStyle`.
   - Встраивание видео — узел с проверенным адресом YouTube или VK; iframe
     строится клиентом из идентификатора ролика, а не из присланного URL.
   - Серверная схема — единственный источник белого списка; документы,
     не прошедшие её, отклоняются `validation_failed`.
3. Запасной вариант — Lexical, если владельцу важнее отсутствие коммерческой
   компании за проектом, ценой большего объёма собственного кода.
