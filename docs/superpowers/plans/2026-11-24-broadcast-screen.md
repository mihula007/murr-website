# Экран рассылок: массовый выбор и упрощение интерфейса — план реализации

> **Для исполнителей:** использовать `superpowers:executing-plans` для последовательного выполнения этого плана. Отмечать шаги чекбоксами.

**Цель:** убрать поиск и лишние пояснения на странице рассылок, сохранить положение списка подписок при фильтрации и добавить массовый выбор получателей по классу для всех страниц.

**Архитектура:** подписки остаются отдельным курсорным запросом без поискового поля; предыдущий результат остаётся смонтированным до прихода нового фильтра, а переход с новым параметром выполняется без прокрутки страницы вверх. Массовые действия последовательно загружают все страницы текущего запроса получателей, затем меняют только исключения этих участников в форме; API отправки и серверные данные не меняются.

**Стек:** React 19, TypeScript strict, TanStack Query, TanStack Form, Vitest, Tailwind CSS 4.

**Спецификация:** `docs/superpowers/specs/2026-11-24-broadcast-screen-design.md`; требования `docs/requirements/14-broadcast.md` BRC-15–17, решение от 24.11.2026.

## Общие ограничения

- Клиент — статические файлы React + Vite на GitHub Pages; backend — Supabase Free и одна Edge Function.
- Стили используют только токены темы.
- Чтение серверного состояния использует `useQuery`/`useInfiniteQuery`; обновление кеша и состояние формы следуют существующим хукам.
- В браузере используется `callApi` из `src/lib/supabase/api.ts`.
- Русский язык интерфейса и документации.

## На что обратить внимание при проверке

- Запрос следующей страницы завершается ошибкой во время массового действия: уже существующие отметки остаются без изменений, пользователь видит ошибку.
- Участники другого класса уже исключены: массовое действие над выбранным классом не сбрасывает эти исключения.
- Фильтр класса показывает менее 50 человек, но общее число его получателей больше 50: действие охватывает все курсорные страницы.
- Смена фильтра подписок задерживается или завершается ошибкой: карточка сохраняет внутреннюю прокрутку и доступное содержимое до обновления.
- Узкое окно браузера: поле класса и две кнопки остаются доступными без горизонтальной прокрутки.
