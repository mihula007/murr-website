# Project Initialization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Создать проверяемую основу веб-приложения без бизнес-логики гильдии.

**Architecture:** Статический React-клиент на GitHub Pages с hash-навигацией TanStack Router. Backend — Supabase Free: Postgres, Auth и Edge Functions. Node.js используется только при разработке и сборке; отдельного runtime-сервера нет.

**Tech Stack:** Node.js 24 LTS, npm, React, TypeScript strict, Vite, TanStack Router и Query, Tailwind CSS 4, shadcn/ui, Vitest, React Testing Library, Playwright, Oxlint, Prettier, Supabase SDK и CLI.

**Spec:** [AGENTS.md](../../../AGENTS.md) и согласованные решения в текущем обсуждении. Последнее поручение владельца разрешает приступить к инициализации.

## Global Constraints

- Backend, включая серверные функции и БД, должен работать в Supabase Free.
- Клиентский хостинг — бесплатный GitHub Pages с собственным доменом.
- Секреты — только локальный игнорируемый `.env` или защищённое хранилище платформы; `.env.example` содержит только пустые значения.
- Реальные секреты никогда не попадают в `VITE_*`, клиентский код или артефакты Pages.
- Не читать и не переносить бизнес-логику `prototype/`.
- Не создавать удалённые проекты, не публиковать сайт и не менять DNS в рамках локальной инициализации.
- Визуальная тема временная, не считается утверждённым дизайном гильдии.

## Review Focus

- Запуск без `.env`: статический каркас открывается без обращения к Supabase.
- Неполная или небезопасная публичная конфигурация: клиент Supabase не создаётся с серверным ключом.
- Прямая вложенная hash-ссылка и неизвестный маршрут: корректное открытие и возврат на главную.
- Проверки npm не обходят реальные ошибки; прототип исключён из проверок нового приложения.
- Pages получает только `dist/`; секреты backend не передаются в frontend-сборку.

## Файлы и границы

- `src/app/` — точка сборки приложения, маршрутизатор и провайдер Query.
- `src/routes/` — корневой и стартовый маршруты, без доменных функций.
- `src/components/ui/`, `src/lib/utils.ts`, `src/styles.css`, `components.json` — минимальная основа shadcn/ui и токены Tailwind.
- `src/lib/supabase/` — проверка публичной конфигурации и создание браузерного клиента.
- `supabase/config.toml`, `supabase/functions/`, `supabase/migrations/` — локальная основа backend без прикладной схемы.
- `tests/`, `e2e/` — тесты границы конфигурации и браузерная проверка навигации.
- `scripts/`, `.github/workflows/` — проверка секретов и сборка/доставка Pages.
- `README.md`, `AGENTS.md`, `.env.example` — команды, ограничения и решения.
