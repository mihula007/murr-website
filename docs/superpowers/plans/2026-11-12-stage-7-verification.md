Сценарий `lists.spec.ts` теперь проверяет и обрезку с подсказкой, а `scrollUntilVisible` прокручивает до конца страницы, а не 60 экранов. Повторный полный прогон — без падений.

## Производительность запросов

`EXPLAIN ANALYZE` на синтетических данных (200 участников × 300 закрытых событий = 60 000 строк итога, транзакция откатана):

| Запрос                        | Время  | План                                                 |
| ----------------------------- | ------ | ---------------------------------------------------- |
| Страница истории (51 строка)  | 0,3 мс | `events_closed_by_start` + bitmap по записям события |
| История участника             | 0,1 мс | `event_activity_records_user`                        |
| Рейтинг / сводка (все записи) | 15 мс  | Полный просмотр записей и hash join — приемлемо      |

## Ручная проверка (встроенный браузер, локальный стек)

Офицер: создание двух групп диалогом, перенос меню строки и перетаскиванием, выбор лидера, «Сохранить как шаблон» (конструктор заполнен распределением события, лидер сохранён), закрытие с подтверждением — событие только для чтения, вкладки итога «Посетили / Не посетили / Не отметились». Учёт активности: сводка, история, «По мероприятию»; рейтинг. Ширины: окно панели (~800 px), 768 и 375 px — без горизонтальной прокрутки, ошибок в консоли нет.

Найдено и исправлено при ручной проверке:

- Объявления dnd-kit для экранного диктора были на английском со служебными id — заменены русскими с ником и группой.
- Полосы вкладок показывали вертикальную прокрутку (подчёркивание активной вкладки выходит за `overflow-x-auto`) — `overflow-visible` у переносящихся полос.
- В карточках рейтинга на узком экране номер выводился отдельным заголовком — заголовок карточки задаётся `data-title`, ячейка номера скрыта.
- Порядок столбцов истории приведён к ACT-06 («дата / мероприятие / участник…»).

Не проверено вручную: член и администратор в браузере (покрыто Vitest и Playwright), реальное открытие `.xlsx` в Excel/LibreOffice (структура проверена тестами `xlsx.test.ts` и сценарием E2E-03), сравнение с прототипом попиксельно.
