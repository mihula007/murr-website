# Обновление страницы «Клан Холл» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Исправить лимит, действия, подсветку и оформить очередь КХ по утверждённому макету.

**Architecture:** Сохранить текущие очереди, API и историю. Разрешить выдачу администратору серверной проверкой и тем же действием клиента, обновить поведение карточек и обработку конфликта лимита, затем перестроить шапку страницы с предоставленным фоном.

**Tech Stack:** React 19, TypeScript strict, Tailwind CSS 4, TanStack Query, одна Supabase Edge Function, Vitest.

**Spec:** [docs/superpowers/specs/2026-11-27-kh-queue-refresh-design.md](../specs/2026-11-27-kh-queue-refresh-design.md)

## Global Constraints

- Работать только в `main`, без новых веток и рабочих копий.
- Не добавлять зависимости; использовать одну Edge Function `api`.
- Все запросы выполняются через `callApi`; записи — через `useMutation`.
- Секреты хранятся только в игнорируемых env-файлах.
- Сохранить данные очереди и истории, роли и адаптацию телефона по требованиям KHQ.

## Review Focus

- Администратор может выдать награду серверным действием; офицер по-прежнему не может.
- Одновременная смена общего лимита и попытка записи обновляет счётчик и список, не показывая общую панель ошибки.
- При достигнутом лимите свободная кнопка и её место отсутствуют.
- Подсветка собственной записи не закрывает ник и управляющие элементы.
- Переключатель повтора у своей записи заметен и продолжает сохраняться.
- На узком экране баннер не вызывает горизонтальную прокрутку, а очередь остаётся аккордеоном.
