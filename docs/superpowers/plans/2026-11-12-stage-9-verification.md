Горизонтальной прокрутки нет на обеих ширинах.

Найдено и исправлено: опрос `discussions/changes` уходил сразу после загрузки ветки — лишний вызов функции на каждое открытие. Первый опрос теперь через 30 с (проверено по сетевым запросам: при открытии только `discussions/list`, через 30 с — `changes`).

Не проверено вручную: долгое нажатие на настоящем сенсорном экране (Radix ContextMenu; в эмуляции клики приходят как мышь), поведение при нескольких открытых вкладках, сравнение с прототипом попиксельно.

## Отличия от плана

- Функции доступа к родителю собраны в `discussions/parents.ts` (вызывает репозитории и правила видимости модулей `events`, `votes`, `publications`, `market`), а не разнесены по четырём модулям: одно место для правила «доступ следует родителю». Репозиториям публикаций и рынка добавлен `lockShared` (`FOR SHARE`).
- Поповер для эмодзи не добавлялся: вставка — тем же `DropdownMenu`. Через CLI shadcn добавлен только `context-menu`; CLI подтянул пакеты `radix-ui` и `cn` — откачено, установлен `@radix-ui/react-context-menu` 2.4.1 (та же `react-menu` 2.2.1, что у выпадающего меню), компонент переоформлен по образцу `dropdown-menu`.
- Лента ветки — компонент `ReverseVirtualList` в `virtual-list.tsx` (правило стилей разрешает `--virtual-*` только там), хук `useElementList`.
- Окно обсуждения на узком экране — во весь экран; закрывается кнопкой и Escape (кликнуть «вне» негде).
- Счётчик `messageCount` — необязательное поле ответов `events`, `votes`, `publications`, `market` (совместимое изменение).
