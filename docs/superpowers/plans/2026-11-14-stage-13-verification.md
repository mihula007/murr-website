Playwright 1.65 не ставит свой Chromium на macOS 13 (`npx playwright install chromium` — «does not support chromium on mac13»). Сценарии запускались временным локальным конфигом с `channel: 'chrome'` поверх `playwright.config.ts` (установленный Google Chrome 157); конфиг не закоммичен. В CI Playwright ставит свой Chromium на Ubuntu, как раньше. Связь функции в Docker на Linux с фальшивым Bot API через `host.docker.internal` (CLI добавляет `host-gateway`) в CI ещё не проверялась.

Найдено e2e: порт 4190 фальшивого Bot API входит в список запрещённых портов `fetch` (ManageSieve) — Node отказывал с «bad port»; порт заменён на 4290.

## Ручная проверка

- **Встроенный браузер, локальный стек** (задача 5, 375 и 1240 px): кабинет — привязан, отвязка с подтверждением, ссылка на бота; «Рассылка» — недоступные ВКонтакте и MAX, ошибки полей при отправке пустой формы, «Отправить некому», плашка анонса события, подтверждение с числом получателей. Горизонтальной прокрутки нет, новых ошибок в консоли нет. Исправлены: двойной пробел перед «— не подключено», упоминание файлов в подсказке шаблонов.
- **Настоящий Telegram** (задача 6, тестовый бот владельца, туннель `npm run telegram:dev`): привязка по ссылке из кабинета; отдельный анонс — текстом без кнопок, `<b>`, `&`, `>` показаны как текст; анонс события — три кнопки; «Приду» в Telegram сохранён на сайте; «Не приду» на сайте обновил сообщение (фоновая задача в настоящей функции); «Изменить решение» вернул три кнопки без смены ответа; повторный анонс события оставил первое сообщение текстом без кнопок и строки ответа, новое — со строкой ответа и «Изменить решение». Аудит — по записи на отправку.

Не проверено вручную: отказ кнопок после начала, закрытия или удаления события, остановка бота (покрыты серверными тестами).

## Замечания

- `npm run test:server` очищает прикладные таблицы локальной БД (`resetAppData`, так было и до этапа): данные ручной проверки после него нужно создавать заново.
- Строка «Ответьте кнопками под сообщением или на сайте…» — часть редактируемого текста из события; на заменённом сообщении она остаётся. Владелец решил оставить как есть.
