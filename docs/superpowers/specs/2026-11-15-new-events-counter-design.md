# Новые события в расписании — согласованный проект

## Зачем

Красная цифра на вкладке «Актуальные» сейчас показывает число всех действующих событий и не исчезает после просмотра. Она должна сообщать о новых событиях, а общее число действующих событий оставаться видимым отдельно.

## Цели и границы

- Красная цифра показывает новые события после последней отметки просмотра раздела для текущего аккаунта.
- Открытие раздела снимает эту новизну по правилам NTF-09–11.
- Общее число актуальных событий показывается обычным текстом; число прошедших событий не меняется.
- Личная история уведомлений, данные событий, права и журнал действий не меняются.

## Подходы

- **Выбран:** использовать существующий счётчик новизны раздела «Ивенты» для красной цифры, а общее число активных событий показывать рядом обычным текстом. Это сохраняет один источник счётчика и согласуется с NTF.
- **Не выбран:** оставить красной цифрой общее число активных событий, а новые события показывать только в меню. Это не отвечает на запрос о цифре на вкладке.

## Ограничения и решение

Сохраняются существующие роли, отметки `section_views` и срок обновления шапки. Красная цифра снимается при первом открытии раздела; новые личные уведомления не создаются. Существующие события не меняются.
