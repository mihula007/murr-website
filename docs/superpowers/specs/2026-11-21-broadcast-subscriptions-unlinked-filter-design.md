# Фильтр людей без привязок во вкладке «Подписки»

## Намерение

Офицерам с правом просмотра подписок и администраторам нужен быстрый способ найти внутренний состав, у которого не привязан ни один поддерживаемый мессенджер.

## Поведение

- Флажок «Показать без подписки» выключен по умолчанию; без него список остаётся прежним и показывает всех участников, офицеров и администраторов.
- При включённом флажке показываются только люди без привязки к Telegram, ВКонтакте и MAX. Заблокированная привязка всё равно считается привязкой.
- Флажок и поиск по нику работают одновременно и сохраняются в адресе страницы. Фильтр применяется до курсорной разбивки; смена поиска или флажка начинает список сначала.
- Если результат пуст, показывается «Людей без привязки не нашли».
- Флажок расположен у поиска; карточки и внутренний список на телефоне остаются прежними.
- Права, рассылки, уведомления, журнал действий и существующие данные не меняются.

## Подходы

Можно отбирать строки только из уже загруженной порции, но тогда результат будет неполным для списка больше 50 человек. Выбран серверный фильтр, который применяется вместе с поиском и до курсорной загрузки каждой страницы.

## Ограничения

Используются текущие React, TanStack Router/Query, zod-контракты и операция `broadcasts/subscriptions`. Новые таблицы, зависимости и данные не нужны.
