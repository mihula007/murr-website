# Устойчивое положение колонок в аккаунтах

## Цель

При прокрутке списка аккаунтов столбцы на компьютере не должны менять ширину и смещать содержимое. На телефоне строки остаются карточками.

## Не входит в изменение

Данные аккаунтов, права, фильтры, сортировка, действия, загрузка страниц и внешний вид карточек на телефоне не меняются.

## Подходы

- Закрепить ширину раскладки таблицы. Выбранный подход: сохранить единое положение колонок, пока виртуальный список показывает разные строки.
- Убрать виртуализацию. Не подходит для списка аккаунтов, который может превышать 50 записей.

## Решение

Причина сдвига — автоматическая раскладка таблицы подстраивает ширины колонок под строки, которые сейчас присутствуют на экране. Для таблицы аккаунтов ширины колонок будут стабильными при прокрутке; мобильная раскладка карточками останется прежней. Изменения данных и поведения не требуется.
