# Обновление экрана рассылок

## Намерение

Упростить подготовку рассылки для офицера и администратора: убрать ненужный поиск и пояснения, дать быстрый способ менять отметки получателей и не терять место в карточке подписок при смене фильтра.

## Цели и границы

- Удалить поиск по нику из «Подписок» и сохранять положение внутренней прокрутки при включении/выключении «Показать без подписки».
- В «Кому отправить» оставить заголовок, удалить оба поясняющих текста, сократить ширину фильтра класса и добавить рядом «Снять отметки» / «Отметить всех».
- Массовые действия применяются ко всем подходящим получателям выбранного класса, даже если их страницы ещё не загружены; «Все классы» охватывает весь список. Отметки других классов сохраняются.
- На узком экране фильтр и кнопки перестраиваются в доступный ряд/столбец без горизонтальной прокрутки.
- Права, профили, черновики, шаблоны, отправки, уведомления и журнал действий не меняются.

## Подходы

1. Загружать все страницы только по нажатию массовой кнопки, затем применять изменения к списку класса. Это сохраняет серверную курсорную пагинацию в обычном просмотре и не меняет контракт отправки; выбранный подход.
2. Заменить список исключений в форме на правило «все включены/выключены, кроме…» и менять серверный контракт отправки. Это лучше масштабируется при очень больших списках, но меняет API и требует совместимого расширения серверной отправки.

## Реализация

Использовать текущий `useInfiniteQuery` для последовательной загрузки страниц текущего класса только во время массового действия; при ошибке не менять отметки и показать понятное сообщение. Сохранение прокрутки карточки подписок обеспечить показом предыдущего результата запроса до завершения загрузки нового фильтра, чтобы прокручиваемый элемент не размонтировался. Удалить параметр поиска из интерфейса и адреса страницы. Вёрстку и подписи держать в существующих компонентах рассылки.

## Ограничения

Сохранять стек проекта и совместимый контракт API. Новые таблицы, секреты и внешние сервисы не нужны. Проверки и ручной показ следуют правилам `AGENTS.md`.
