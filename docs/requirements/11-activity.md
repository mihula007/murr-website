# Посещения, учёт активности и рейтинг

Роли: рейтинг и топ-5 доступны внутренним ролям; детальный учёт и экспорт — офицер/админ.

Источники: UI рейтинга и всех четырёх вкладок учёта; закрытие тестового события с появлением 13 строк; скачивание Excel. Код: `buildActivityRecord`, `buildActivitySummary`, `renderMonthlyAttendanceTop`, `getFilteredActivityRecords`, `renderActivityAnalytics`, `exportActivityWorkbook`, `buildAttendanceRatingRows`.

## Снимок закрытого мероприятия

| Условие на момент закрытия                                 | Статус       |
| ---------------------------------------------------------- | ------------ |
| Человек включён в сохранённую группу, независимо от ответа | Посетил      |
| Не включён в группу и выбрал любой ответ, включая «Приду»  | Не посетил   |
| Не включён в группу и не ответил                           | Не отметился |

Ответ — намерение; включение в итоговую группу — источник факта посещения. Ручной отдельной отметки фактического присутствия после закрытия не найдено.

## Требования

- `ACT-01` Закрытие события создаёт один снимок: идентификатор и название события, тип, исходные день/время, время закрытия, группы, лидеры, участники с именем/ником/классом и итоговым статусом.
- `ACT-02` В снимок попадает актуальный состав на момент закрытия и назначенные в группы люди согласно коду. Позднее вступивший участник не получает «Не отметился» задним числом в уже существующем снимке.
- `ACT-03` Снимок хранится независимо от дальнейшего изменения профилей и состава; при удалении пользователя его отметки и сведения удаляются согласно ACT-17; чтец остаётся в истории. Повторное посещение раздела не добавляет копию. Код восстанавливает недостающие снимки старых закрытых событий из доступных данных; такую миграцию не считать достоверной историей, если данные утрачены.
- `ACT-04` Сводка участников учитывает только завершённые мероприятия и показывает ник, класс, количества «Посетил», «Не посетил», «Не отметился» и процент. Пати-лидерство в этой сводке не показывается.
- `ACT-05` В сводке процент = округлённое до целого `посетил / число записей этого участника в отобранных снимках × 100`; при отсутствии записей показано 0%.
- `ACT-06` История показывает строки «дата / мероприятие / участник / класс / группа / посещение». Отсутствующая группа обозначается нейтральным маркером, не вымышленным назначением.
- `ACT-07` Вкладка «По мероприятию» выбирает событие и показывает его состав, классы, группы и статусы, а также количества всего/посетили/не посетили/не отметились.
- `ACT-08` Вкладка «По участнику» выбирает участника и показывает его сводные показатели и историю «дата / событие / группа / посещение». При отсутствии выбора/данных отображается пояснение.
- `ACT-09` Общие фильтры: период с/по и класс, поиск по участнику/мероприятию; есть сброс. Фильтры согласованно применяются к показателям, строкам и экспорту. Excel формируется с активными фильтрами на момент экспорта.
- `ACT-10` В учёте используются только завершённые мероприятия; дата мероприятия берётся из сохранённого события.
- `ACT-11` «Выгрузить Excel» скачивает `.xlsx` с листами «Рейтинг» и «История мероприятий», применяя выбранные на момент экспорта фильтры. Книга содержит табличные значения и заголовки.
- `ACT-12` Главная показывает топ-5 текущего месяца для текущих членов. Код ранжирует по числу посещений, затем проценту, затем нику; в топ попадают только имеющие посещение. Отображаются посещения/число событий участника, процент, класс, при наличии пати-лидерства.
- `ACT-13` Если закрытых мероприятий/посещений нет, главная сообщает об отсутствии данных вместо вымышленных лидеров.
- `ACT-14` Отдельный «Рейтинг посещения» показывает номер, ник, класс, три счётчика посещений, процент, число случаев пати-лидерства и дни в гильдии. Показатель пати-лидерства — количество раз, когда участник был лидером группы. Есть поиск по участнику и сортировка по каждому содержательному столбцу.
- `ACT-15` В рейтинге неизвестные дата вступления/процент обозначаются «—»; дни считаются полными сутками с даты вступления.
- `ACT-16` Сводка и рейтинг строятся по сохранённым данным завершённых мероприятий. Рейтинг дополнительно включает число случаев пати-лидерства; сводка его не показывает.

- `ACT-17` После удаления пользователя его отметки посещения и сведения о нём полностью удаляются из истории и аналитики; показатели пересчитываются по оставшимся данным. При переходе в чтецы аккаунт и его исторические записи сохраняются и остаются видимыми для ролей, которым доступна история.

## Приёмка

1. Перед закрытием подготовить A в группе, B ответившего вне группы, C без ответа вне группы: получить «Посетил», «Не посетил», «Не отметился» соответственно.
2. Закрыть один раз, повторно открыть учёт и перезагрузить: одна запись события. Изменение ника/класса не меняет историческую строку.
3. Сводка и рейтинг включают только завершённые события и сохраняют исторические записи участника.
4. Выбрать период/класс, проверить четыре представления и экспорт одной выборки. Открыть книгу в табличном приложении, сверить оба листа и числа с UI.
5. Проверить ноль событий, ничью топ-5, исключённого участника и границу месяца/часового пояса.

Открытые решения реализации: точный выбор даты для периодов и детали формул процентов. [Снимок аналитики](evidence/activity-admin.jpg).
