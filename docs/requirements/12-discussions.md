# Чаты и обсуждения

Роли: внутренние роли; доступ и возможность записи дополнительно определяются родительским объектом. Кандидаты/чтецы не получают внутренние ветки.

Источники: UI чата события, отправки, формы редактирования, реакции, меню «кто прочитал», обсуждения голосования; код `renderEventChatContent`, `sendEventChat`, `chatMessageCanBeEdited`, `toggleEventChatReaction`, `notificationRecipientsForChat`, `isClosedVoteDiscussion`, `markChatMessageRead`.

## Требования

- `DSC-01` Отдельные ветки существуют для события, голосования, публикации и объявления. Ветка события отображается рядом с группами; остальные открываются отдельным окном. Счётчик отражает число сообщений конкретной ветки.
- `DSC-02` У сообщения видны автор, аватар или начальная буква, роль офицера/админа при наличии, время, текст; сообщения разделены датами, свои визуально отличаются от чужих.
- `DSC-03` Отправляется непустой после trim текст до 2000 символов. Способ отправки — кнопка либо Ctrl+Enter / Cmd+Enter. Простое Enter допускает многострочный текст (Код).
- `DSC-04` Отправленное сообщение сохраняется в своей ветке и появляется в истории; текст отображается безопасно как текст, а не исполняемый HTML.
- `DSC-05` «Ответить» выбирает сообщение, показывает предварительную цитату и позволяет отменить ответ. Отправленный ответ содержит автора/текст цитаты; не заменяет исходное сообщение.
- `DSC-06` Выбор эмодзи вставляет символ в место курсора. Набор вставляемых эмодзи может отличаться от набора реакций.
- `DSC-07` Упоминание `@ник` и ответ другому автору создают личное уведомление адресату, если аккаунт найден. Отправителю уведомление самому себе не создаётся. Код сопоставляет упоминания по нику/имени без пробелов и без учёта регистра; стабильная идентичность — Q-12.
- `DSC-08` Автор может редактировать своё сообщение в течение 5 минут с создания. При открытии и при сохранении повторно проверяется срок; пустая правка запрещена, «Отмена» оставляет прежний текст.
- `DSC-09` После срока кнопка редактирования исчезает. Офицер/админ не получает отдельного права править чужие сообщения. Удаление и модерация сообщений не обнаружены, Q-20.
- `DSC-10` Правый клик открывает меню реакций и сведений о сообщении. Фактический набор: ❤️ 👍 👎 😂 🔥 😢 😭 😐 👌 😮. README перечисляет лишь пять — ориентироваться на наблюдаемое меню до решения владельца.
- `DSC-11` Аккаунт может выбрать несколько разных реакций, но по одной отметке каждого вида на сообщение. Повторный выбор снимает собственную отметку. Видны счётчик и собственный выбор; есть просмотр поставивших реакции (Код, UI меню).
- `DSC-12` Для собственных сообщений показывается состояние прочтения, предусмотрен список прочитавших. Код отмечает видимые чужие сообщения; семантика реального прочтения и приватность списка — Q-20.
- `DSC-13` У завершённых событий/голосований история читается, но отправка, ответы, правка и изменение реакций закрыты. Читаемость архива не даёт право менять его через старую форму.
- `DSC-14` Обсуждение материала доступно только при публикации и разрешении автора. Снятие публикации/выключение обсуждения запрещает запись; удаление родительского материала очищает его ветку (Код).
- `DSC-15` Окно обсуждения можно закрыть кнопкой, Escape и кликом вне него; после закрытия фокус возвращается к инициатору (Код для голосований/контента).

- `DSC-16` После удаления пользователя его сообщения сохраняются в обсуждениях без связи с автором, с сохранением связей ответов. Вместо автора показывается «Пользователь удалён».

- `DSC-17` При удалении пользователя его реакции сохраняются обезличенно, а отметки прочтения удаляются; связи с его аккаунтом не остаётся.

## Приёмка

1. Отправить сообщения в два разных объекта: истории не смешиваются. Пустое/пробельное сообщение не появляется.
2. Ответить другому участнику, вставить эмодзи и упомянуть третьего: цитата сохранена, нужные получатели видят уведомления без уведомления самому отправителю.
3. Автор правит своё сообщение до пяти минут; другой аккаунт не может. Проверить сохранение после истечения срока даже при заранее открытой форме.
4. Поставить две разные реакции и снять одну; счётчики не дублируют аккаунт. Проверить меню читателей/реакций.
5. Оставить окно открытым и завершить родительский объект: дальнейшие изменения запрещены; история сохранена.

Мобильная альтернатива правому клику, правила прочтения и модерация — Q-20. Вложения в чат и полноценный отдельный мессенджер не обнаружены.
