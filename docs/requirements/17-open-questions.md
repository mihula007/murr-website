# Решения владельца и оставшиеся вопросы

Эта страница фиксирует ответы владельца от 08.11.2026. Решения заменяют наблюдавшееся в локальном прототипе поведение там, где оно расходится. Прототип и новое приложение не изменялись.

## Решённые вопросы

| ID        | Принятое решение                                                                                                                                                                                                                                                               |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Q-01      | Гость, кандидат и чтец не видят состав клана ни на главной, ни на странице состава.                                                                                                                                                                                            |
| Q-02–Q-03 | Публикации создают офицеры и администраторы. Офицер редактирует только свои материалы; администратор — любые.                                                                                                                                                                  |
| Q-04      | Внутренние объявления создают члены и офицеры. Каждый управляет своими объявлениями и видит только свои черновики; администратор управляет всеми объявлениями и черновиками.                                                                                                   |
| Q-05      | Проект начинается с нуля: у каждого события есть создатель, сохраняемый в истории после завершения. Закрытое событие повторно не открывается; для повторения создаётся новое с перенесёнными данными.                                                                          |
| Q-06      | У пользователя не может быть более одной активной заявки. После отказа нет специального ограничения на новую заявку.                                                                                                                                                           |
| Q-08      | Четыре фиксированных еженедельных события работают по московскому времени (UTC+3), независимо от часового пояса браузера.                                                                                                                                                      |
| Q-09      | Сводка участников включает только завершённые мероприятия и не показывает пати-лидерство. Рейтинг посещений показывает число случаев, когда участник был пати-лидером.                                                                                                         |
| Q-10      | Новые аккаунты используют Supabase Auth с email и паролем; адрес подтверждается одноразовым кодом из письма. Старых аккаунтов нет.                                                                                                                                             |
| Q-11      | Аватар: JPEG/PNG/WebP, до 500 KB. Заявки и объявления не принимают файлы, допускают ссылки. Публикации принимают изображения JPEG/PNG/WebP до 1 MB.                                                                                                                            |
| Q-12      | Используется Supabase Auth; у каждого пользователя стабильный уникальный ID.                                                                                                                                                                                                   |
| Q-13      | Аккаунты не удаляются. Исключённый теряет доступ и блокируется, оставаясь в базе.                                                                                                                                                                                              |
| Q-14      | Устаревшие остатки прототипа не являются частью требований и не включаются в документацию.                                                                                                                                                                                     |
| Q-15      | Все поля регистрации обязательны, кроме скриншота снаряжения. Поля: email, пароль, имя, игровой ник, город, дата рождения, класс персонажа, рассказ о себе, аватар. Профиль доступен только владельцу и администратору; другим ролям показывается игровой ник.                 |
| Q-16      | Офицеры и администраторы видят автора каждого голоса; членам показываются только количества голосов по категориям. Ничьи и дополнительные смыслы голосов отдельно не обрабатываются: решение принимают офицеры на своё усмотрение.                                             |
| Q-17      | На всех страницах при уходе с несохранёнными изменениями показывается подтверждение.                                                                                                                                                                                           |
| Q-18      | Экспорт Excel учитывает активные фильтры на момент запуска экспорта.                                                                                                                                                                                                           |
| Q-19      | Закрытое событие нельзя открыть снова. Для повторного проведения создаётся новое событие с переносом необходимых данных.                                                                                                                                                       |
| Q-20      | Дополнительные функции чата не добавляются; сохраняется имеющийся набор возможностей.                                                                                                                                                                                          |
| Q-21      | После подачи заявки пользователь перенаправляется на главную.                                                                                                                                                                                                                  |
| Q-22      | Интеграции с мессенджерами реализуются отдельно от сайта.                                                                                                                                                                                                                      |
| Q-23      | Журнал хранится на сервере и показывает последние 1000 записей. Аудируемые действия перечислены в ADM-11. При добавлении любого действия, меняющего состояние системы, необходимо явно решить, должно ли оно попадать в журнал (правило также добавлено в корневой AGENTS.md). |
| Q-24      | Регистрация автоматически создаёт заявку. Офицеры и администраторы могут принять участника без голосования; такой приём обязательно записывается в журнал аудита.                                                                                                              |
| Q-25      | Кнопка «Весь учёт» видна только офицерам и администраторам.                                                                                                                                                                                                                    |

## Прочие вопросы реализации

Точные сроки хранения прочих данных, корректировка исторических снимков, кворум голосований и детализация фильтров/формул не расширяются сверх решений выше; до реализации соответствующего блока требования уточняются с владельцем. Они не должны переоткрывать явно принятые ответы.
