# Публикации и общий редактор материалов

Роли: опубликованное читают внутренние роли; создавать материалы могут офицеры и администраторы. Офицер управляет только собственными публикациями и черновиками; администратор — любыми материалами и черновиками.

Источники: UI редактора, предпросмотра, сохранения черновика и публикации, чтение участником; код `renderClanPublications`, `saveClanPublication`, `sanitizePublicationHtml`, `handlePublicationFiles`, функций просмотра медиа. Общий редактор также используется рынком с другими правами.

## Требования к материалам

- `PUB-01` Лента показывает категорию, заголовок, краткое описание при наличии, оформленное содержимое, вложения, время обновления и разрешённую подпись автора. Сортировка — по последнему обновлению, новые сверху (Код).
- `PUB-02` Поля редактора: обязательный заголовок, категория (Статья / Объявление / Новость / Гайд / Правила), необязательный анонс, содержимое, вложения, флаги подписи автора и обсуждения.
- `PUB-03` Сохранение без заголовка отклоняется. Нужен текст либо изображение/таблица/линия в содержимом, либо вложение; допустимость материала только с линией — Q-17, правило кода не следует считать осмысленным контентным решением.
- `PUB-04` Предпросмотр показывает будущий материал с форматированием и вложениями; возврат к редактированию не теряет поля. Сам предпросмотр не публикует и не сохраняет объект.
- `PUB-05` Доступны явные «Сохранить черновик» и «Опубликовать». Черновик виден его автору и администратору; обычным участникам — только опубликованный материал.
- `PUB-06` Автор-офицер может открыть и изменить, опубликовать, снять с публикации или удалить собственный материал с подтверждением. Администратор может выполнить эти действия с любым материалом. Автор и время создания не заменяются при редактировании.
- `PUB-07` Подпись автора необязательна для читателей. Редакторы видят автора для управления даже при выключенном флаге; это не анонимность перед администрацией.
- `PUB-08` Обсуждение доступно только опубликованному материалу с включённым флагом. Ветка и счётчик отдельные для каждого материала (DSC).
- `PUB-09` Поиск без учёта регистра охватывает заголовок, категорию, анонс, автора, текст и имена вложений. Очистка возвращает полную разрешённую ленту; пустой результат имеет отдельное сообщение (Код).

## Требования к редактору

- `PUB-10` Поддержать жирный/курсив/подчёркивание/зачёркивание, обычный текст/заголовок/подзаголовок/цитату, размер и цвет текста, выравнивание, маркированный и нумерованный списки, отступы.
- `PUB-11` Поддержать добавление/снятие ссылки, изображение по URL, таблицу, специальные символы, горизонтальную линию, отмену/повтор и очистку форматирования. Эти инструменты осмотрены в UI, все комбинации форматирования не проверялись.
- `PUB-12` Сохраняемый и отображаемый HTML очищается от исполняемого содержимого и недопустимых атрибутов. Код разрешает ссылкам HTTP/HTTPS/mailto, изображениям HTTP/HTTPS. Сохранение произвольного HTML как доверенного содержимого недопустимо; серверная защита — отдельная реализация GEN-02.
- `PUB-13` К публикации можно прикрепить изображения JPEG, PNG или WebP размером до 1 МБ каждое; прочие типы файлов запрещены. Доступны просмотр списка и удаление вложения до сохранения.
- `PUB-14` Прикреплённые изображения отображаются; при недоступном файле показывается сообщение, материал остаётся читаемым.
- `PUB-15` Последовательные изображения/видео объединяются в галерею с предыдущим/следующим элементом и счётчиком; предусмотрены увеличенный просмотр, полноэкранный режим и жест перелистывания. Это подтверждено кодом, не полным UI-тестом медиа.
- `PUB-16` При удалении материала удаляются связанные вложения и обсуждение (Код). Закрытие несохранённого редактора очищает его новые, не используемые другими материалами файлы; вопрос предупреждения о несохранённом тексте — Q-17.

## Приёмка

1. Офицер создаёт черновик с форматированием; участник не видит его. После публикации тот же участник видит материал без управляющих кнопок.
2. Выключить подпись автора: читатель не видит подпись, администратор сохраняет сведения об авторе.
3. Включить обсуждение и опубликовать: появляется отдельная ветка. Снятие с публикации не позволяет продолжить общение через старое открытое окно.
4. Прикрепить картинку, видео, аудио и документ; проверить отображение, скачивание и контролируемый недоступный файл. Удалить материал — проверить согласованную очистку.
5. Поиск по содержимому и имени файла находит материал; очистка сбрасывает поиск. Опасная ссылка/разметка не исполняется.

Открытые вопросы реализации: Q-13 (связанные исторические данные), Q-17 (глобальная защита несохранённых изменений).
