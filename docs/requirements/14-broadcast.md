# Подготовка рассылок

Роли: офицер/админ. Источники: UI общей формы, заполнение из события, сохранение шаблона и черновика; код `showTelegramNotice`, `openTelegramEventNotice`, `openTelegramVoteNotice`, `openTelegramGroupNotice`, `createTelegramBroadcastDraft`, `handleTelegramBroadcastFiles`.

## Граница функционала

**Интеграции с мессенджерами и их отправка не входят в требования этого сайта; они будут реализованы отдельно.**

## Требования

- `BRC-01` Общая форма содержит тему, обязательный текст, вложения и флаги каналов Telegram / ВКонтакте / MAX. Изначально выбраны все три.
- `BRC-02` Из актуального события подготовка заполняет тему и текст названием, типом, датой/временем и описанием.
- `BRC-03` Из актуального голосования подготовка заполняет тему, контекст и приглашение выбрать ответ на сайте. Из закрытого голосования/события подготовка недоступна.
- `BRC-04` Из непустой группы подготовка перечисляет состав в порядке группы, с отметкой лидера и числом предполагаемых получателей. Настоящий список адресов мессенджеров не формируется; Q-22.
- `BRC-05` Текст после автоматической подготовки можно изменить. Открытие из контекста сбрасывает текущие выбранные файлы и включает каналы (Код); необходимость предупреждения о потере несохранённого — Q-17.
- `BRC-06` Черновик сохраняется только с непустым текстом и минимум одним каналом. Тема необязательна, в списке есть запасное название.
- `BRC-07` После сохранения видны тема, время, текст, каналы, список имён вложений, автор и явный статус «Черновик · отправка после подключения». Поля текста/темы и выбранные файлы очищаются.
- `BRC-08` Допустимы до 10 файлов, каждый не больше 20 МиБ: XLS/XLSX, DOC/DOCX, TXT, RTF, ODT/ODS, PNG/JPG/WebP/GIF. Код отбрасывает неподдерживаемые/слишком большие и сообщает ошибку; повторы по имени/размеру/времени не добавляются.
- `BRC-09` Важное ограничение: сохранённый черновик хранит только метаданные файлов, не их содержимое. Восстановить отправляемые файлы из такого черновика после перезагрузки нельзя; желаемое хранение — Q-22.
- `BRC-10` Можно сохранить именованный шаблон с темой, текстом и каналами; название и текст обязательны. Вложения в шаблон не включаются. Предел — 20 шаблонов.
- `BRC-11` Применение шаблона заполняет тему/текст/каналы; шаблон можно удалить. Редактирования существующего шаблона отдельной формой нет.
- `BRC-12` Список черновиков ограничен последними 100 в коде, черновик можно удалить. Редактирование сохранённого черновика/история доставки в UI не найдены.
- `BRC-13` Сохранение черновика не должно представляться успешной отправкой. При неподключённых платформах «Отправить рассылку» недоступна, экран объясняет причину.
- `BRC-14` Подготовка черновика отражается в административном журнале. Код записывает категорию «Рассылка», хотя в фильтре журнала нет такой отдельной категории (Q-23).

## Приёмка

1. Открыть подготовку из события, голосования и непустой группы: текст соответствует выбранному объекту; сеть/боты ничего не отправляют.
2. Пустой текст и ни одного выбранного канала не дают сохранить черновик. Валидный ввод появляется в списке с автором/временем/статусом.
3. Применить сохранённый шаблон: значения и каналы восстановлены, вложения не выдуманы.
4. Проверить неподдерживаемый файл, 11 файлов и файл свыше 20 МиБ; пользователь видит, какие файлы приняты.
5. Для будущей серверной версии отдельно согласовать и проверить сохранность содержимого вложений, адресатов, повторы, частичные ошибки и статусы доставки; прототип этих гарантий не даёт.
